# Stage1stForumTUI

Stage1st 论坛的非官方终端浏览器，基于 Python + Textual。支持浏览版面、主题和帖子；站点提供签到入口时可在登录后自动签到。

## 项目声明

本项目以 Vibe Coding 的方式开发，代码由 AI 生成并经人工提出需求、审阅和调整。它是社区第三方项目，与 Stage1st 论坛及其运营方没有官方关联，也不代表其立场。

论坛帖子、图片及商标等内容归各自权利人所有。本程序仅在用户使用时读取公开网页；请遵守论坛规则，并尊重内容作者的权益。

## 运行

需要 Python 3.10 或更新版本：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m s1tui
```

已有 `.venv` 并安装过依赖时，只需运行最后一行。也可以先执行 `.\.venv\Scripts\Activate.ps1`，然后运行 `python -m s1tui` 或 `stage1st-forum-tui`。旧命令 `s1-forum-tui` 和 `s1tui` 仍可使用。未激活虚拟环境时，`py -m s1tui` 使用系统 Python，可能因缺少依赖而报错。

## 操作

按 `?` 可在程序内查看完整快捷键。底部只显示常用操作提示。

- `j` / `k`：在版面/主题列表中下移/上移；阅读帖子时向下/上滚动约三分之一屏
- `↑` / `↓` / `←` / `→`：分别与 `k` / `j` / `h` / `l` 相同；方向键不会占用界面底部的快捷键提示
- `g` / `G`（`Shift+g`）：跳到当前列表首项/末项；阅读帖子时跳到本页顶部/底部
- `Tab`：在版面栏和主题栏之间切换焦点；阅读帖子时按 `Tab` 返回主题列表；`Enter` 打开当前栏选中的版面或主题
- `h` / `l`：上一页/下一页，`Enter`：打开
- `p`：输入页码并按 `Enter` 直达；`Esc` 取消。标题显示当前页/总页数，最后一页不会继续翻页
- `Shift+L`：登录；输入用户名并按 `Enter` 切到密码，输入密码后按 `Enter` 提交；`Esc` 取消
- `Shift+X`：清除本机登录会话
- `i`：切换图片预览；默认只显示图片占位文字
- `Backspace` / `Esc`：返回
- `r`：刷新，`o`：在系统浏览器打开当前帖子，`q`：退出

图片预览开启后会把图片缩放成终端彩色字符；每张图片最多下载 4 MiB，每页最多预览 8 张，单张尺寸限制为 2000 万像素。若图片源不可达或格式不支持，会显示失败占位。需要终端支持真彩色以获得较好的效果。

阅读帖子时，右侧内容区会占满可用高度并显示独立滚动条；`j` / `k` 每次滚动约三分之一屏。

登录成功后仅将论坛会话 Cookie 保存在系统凭据库，不保存密码。下次启动时若会话仍有效，程序会检查新版 `muanyun_053` 签到页的今日记录，并在尚未签到时尝试自动签到；首次登录后也会执行一次检查。底部持续显示账号和签到状态；只有论坛明确返回成功或今日已签才显示对应状态。若登录后的页面没有签到入口，程序会显示“状态未知（未找到签到入口）”。若论坛要求验证码或安全提问，请在网页中登录。当前版本尚不支持发帖、回复或收藏。论坛访问策略、HTML 结构或网络限制变化时，登录和签到逻辑可能需要调整。
